# 🎓 Student Performance Prediction System

## 🚀 Overview
This project predicts student performance based on academic and behavioral data using machine learning.  
It is an end-to-end system that includes data processing, model training, backend API, and a frontend dashboard.

---

## 🎯 Problem Statement
Educational institutions often struggle to identify students at risk early.  
This system analyzes multiple student-related features and predicts performance to help take timely actions.

---

## ⚙️ Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning Model Training
- Performance Prediction API (Flask)
- Interactive Dashboard for visualization
- Student risk analysis & recommendations

---

## 🧠 Machine Learning
- Models Used:
  - Random Forest
  - Logistic Regression

- Evaluation Metrics:
  - Accuracy: **87%**
  - F1 Score: **0.85**

---

## 🛠️ Tech Stack
- **Backend:** Python, Flask  
- **ML:** Scikit-learn, Pandas, NumPy  
- **Database:** SQLite  
- **Frontend:** HTML, CSS, JavaScript / React (if used)

---

## 🔄 Workflow
1. Load dataset (CSV)
2. Data preprocessing & feature engineering
3. Train ML model
4. Save trained model
5. API handles prediction requests
6. Results displayed on dashboard
